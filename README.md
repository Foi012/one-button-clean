# One Button · 入口收纳

把不常用的悬浮入口收起来，让聊天界面清爽一点。

## 01/适用场景

装了几个酒馆插件后，屏幕上多了好几个悬浮球：有的用来打开面板，有的点击就开始生成，还有一些不常用，却一直挡在界面上。

One Button 让你自己决定哪些入口留在外面，哪些收进同一个面板。常用的照常使用，不常用的需要时再打开收纳区操作，适合希望减少界面遮挡的 SillyTavern 用户。

## 02/功能介绍

- **逐项收纳**：面板列出检测到的入口，每项旁边一个开关。开启后收进面板，关闭后恢复在外。
- **按需检测**：每次打开面板自动检测入口，也可以点击“刷新”。新发现的入口默认不收纳，之前的“全部收纳”不会影响后来新增的插件。
- **入口方式可选**：在面板底部选择“菜单”“悬浮球”或“菜单＋悬浮球”，切换立即生效。
- **分设备记忆**：不同浏览器、电脑和手机可以分别保留自己的收纳选择、入口方式与悬浮按钮位置。

## 03/安装

**通过仓库安装**

1. 打开 SillyTavern 的 **扩展 → 安装扩展**。
2. 填入仓库地址：

   ```text
   https://github.com/Foi012/one-button-clean
   ```

3. 安装完成后刷新酒馆页面。

**开始使用**

安装后，从输入框旁的 **扩展菜单 → 入口收纳** 打开面板，开启想收纳的入口即可。默认使用菜单入口；如果喜欢悬浮球，可以直接在面板底部切换。

也可以从 **扩展设置 → One Button · 入口收纳** 打开面板、调整主题或恢复全部入口。

请使用支持原生 Popover API 的新版浏览器。仓库安装支持在扩展设置中手动检查更新；文件版需要下载新版覆盖。
