# One Button · 入口收纳

**3.0.2** · 常用的留在外面，不常用的收在同一个面板。

## 使用

打开酒馆输入框旁的 **扩展菜单 → 入口收纳**。面板直接列出检测到的悬浮入口：

- **逐项收纳开关**：开启后，关闭面板时隐藏原入口；打开面板时，原控件出现在对应行内，可以直接点击、生成或停止。关闭开关则恢复在外。
- **全部收纳总开关**：全关时开启当前列表中可收纳的入口；部分开启时显示中间态，点击全部开启；全开后再点击全部关闭。
- **刷新**：重新检测当前入口；每次打开面板也会自动检测。新发现的入口默认关闭，不继承之前的“全部收纳”。
- **入口方式**：面板底部直接选择 **菜单 / 悬浮球 / 菜单＋悬浮球**，立即生效。

只有一张列表，没有管理层、添加窗口、搜索、排序或临时显示。操作原控件前不需要再次把它显示到原位置。

入口识别只读取 DOM/布局，不调用插件功能。切换收纳开关不会启动生成。面板中的图标为原节点，保留真实鼠标、触屏和事件委托，不代发点击事件，也不把节点搬出原来的父元素。

## 安装与升级

解压 `one-button-v3.0.2.zip`，把其中的 `one-button` 文件夹放到：

```text
SillyTavern/data/<用户目录>/extensions/one-button/
```

默认用户通常是 `default-user`。确保 `manifest.json` 直接位于该文件夹，重启或刷新酒馆加载。升级时覆盖同一目录，旧收纳名单、主题和入口偏好会迁移。旧版处于暂停状态时，迁移为全部不收纳。

从 Git 安装：在酒馆的 **扩展 → 安装扩展** 中填写 [仓库地址](https://github.com/Foi012/one-button)，安装后刷新页面。

运行时无第三方依赖。需要支持 `SillyTavern.getContext()`、酒馆扩展设置 API 和浏览器原生 Popover API。

## 主题与设置

默认跟随酒馆的背景、正文和强调色，支持浅色与深色，面板颜色仅作用于本插件。原悬浮控件保留各自的颜色与图案。

入口方式直接在主面板切换。酒馆 **扩展设置 → One Button · 入口收纳** 中还可以选择跟随酒馆/浅色/深色、重置悬浮按钮位置，以及应急恢复全部入口。

配置按当前酒馆账户、浏览器设备标识分别保存。电脑、手机可以有不同名单和位置。清理浏览器本地存储会产生新标识，需重新设置。

## 兼容性

原控件保持原 DOM 位置，通过手动 Popover 顶层呈现在列表槽位内。关闭面板、关闭收纳或禁用插件时，释放顶层状态，恢复原来的定位、尺寸和样式。

- 小剧场生成器：以整球外层收纳，图片和点击热区保持整体。
- 生鱼片工具箱：保留 Shadow DOM 内的原生指针事件；展开后释放原宿主，让完整面板显示。
- 楼内预设快切：保留原按钮和同级面板，打开插件面板后收起收纳面板。
- 回声工具箱：关联计时标签随收纳维护。
- 小型 iframe：保留原框架节点，内部真实输入仍由原插件处理；不会读取跨域内容。

已收纳入口重建时会轻量重新匹配；不会为发现新入口而持续扫描整页。暂时缺失的已收纳入口保留在列表，标记“当前未显示”；可关闭开关。

已有自身 Popover 状态或无法安全呈现的入口不会被强行接管，显示“暂不支持收纳”并留在外面。未知的展开面板、特殊拖动行为仍可能需要适配。收纳区以直接点击操作为主；需要拖动原悬浮球调整位置时，先关闭它的收纳开关。详见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 更新和验证

酒馆扩展设置中的版本区域支持手动检查、明确点击更新，再刷新页面。不自动下载或执行外部脚本；本地解压版通过下载新版覆盖更新。

```sh
npm ci
npm run check
npm test
```

测试默认使用已安装的 Google Chrome，可用 `CHROME_PATH` 指定其他 Chrome/Chromium。使用模拟酒馆和独立参考控件验证，不等同于全部真实插件集成验收。
